# Quality and testing

## Layers

- Unit: domain rules, validation and deterministic transformations.
- Integration: NestJS modules, Prisma data access, authorization and AI response validation.
- E2E: user flows from acceptance criteria using Playwright.

## Required evidence

Each completed issue links its acceptance criteria, executed checks, outcome, gaps and defect classification. QA distinguishes product defect, test defect, environment defect and missing requirement.

## Core flows

Authentication/profile; generated and edited meal plans; recipe details; shopping-list refresh; adherence logging; responsive web behavior.
