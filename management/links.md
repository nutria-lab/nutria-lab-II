# Enlaces del proyecto

Este archivo es la fuente central de enlaces de NutrIA. Todos los agentes y workflows deben consultar este registro antes de usar un recurso del proyecto. Guardar aquí los nuevos enlaces autorizados, con un nombre descriptivo, y referenciar este archivo desde las instrucciones que los necesiten.
